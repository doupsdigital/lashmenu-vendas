# Módulo de Prospecção - LashMenu

Este módulo é dedicado à prospecção qualificada de **Lash Designers** utilizando dados extraídos via **Apify** (como Google Maps Scraper).

## Visão Geral da Estratégia
- **Público Alvo:** Lash Designers cadastradas no Google Maps.
- **Diferencial:** Possuem nível de consciência de mercado digital, endereço fixo/estúdio, presença online e interesse em captar clientes.
- **Objetivo:** Extrair contatos (Nome, Telefone/WhatsApp, Endereço, Avaliações, Website) para abordagem direta de vendas do **LashMenu**.

## Estrutura do Módulo
- `.env` (na raiz): Guarda o token `APIFY_API_TOKEN`.
- `apify_service.py`: Módulo para integração e chamada dos Scrapers da Apify.
- `README.md`: Documentação e próximas etapas de prospecção.
