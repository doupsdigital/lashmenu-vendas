Ejetar para Edição de Código Customizado

Se esta cliente solicitar uma personalização extrema que requeira alteração no código HTML/CSS da página (ex: uma nova seção dedicada de depoimentos ou integração de chat especial), você pode ejetá-la para código físico individual de forma simples:

1. Copie o template correspondente (ex: harmonia-rose) na raiz do projeto local. 2. Renomeie a pasta de cópia com o slug da cliente e cole dentro do diretório /clientes/{slug}/. 3. Customizar e programar livremente o HTML/CSS/JS da cliente dentro dessa pasta exclusiva. 4. Exclua (ou mude o slug no Supabase) o registro desta cliente para que a URL do subdomínio passe a puxar automaticamente o código customizado da pasta física local.
